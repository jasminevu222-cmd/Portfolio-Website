# Jasmine Vu Portfolio

A GitHub Pages-ready portfolio website built from Jasmine Vu's resume.

## Files

- `index.html` — main portfolio page
- `styles.css` — custom responsive styling

## How to publish on GitHub Pages

1. Create a new GitHub repository, such as `jasmine-portfolio`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.
6. GitHub will publish the site at a URL like `https://yourusername.github.io/jasmine-portfolio/`.

## Customize

- Replace the placeholder LinkedIn link in `index.html` with the real LinkedIn URL.
- Add project screenshots or campaign examples as image files, then link them in the Work section.
